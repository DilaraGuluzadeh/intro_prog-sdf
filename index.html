Exam rules
  1. The exam is taken in full-screen mode.
  2. Switching to another window or tab (including Alt+Tab), minimising the browser, leaving full-screen mode and reloading the page are rule violations.
  3. At the third violation the exam is cancelled automatically and the result is recorded as 0 points.
  4. Ctrl+C / Ctrl+V work only inside the exam: you can copy from the task text and from your own code into the answer boxes, but you cannot paste text from outside or copy the tasks out of the exam. Right-click and the browser developer tools are blocked.
  5. There is one task per page. You can move between tasks at any time — everything you write is saved.
  6. In coding tasks you can check your solution with the «Check code» button. Your function may return or print its answer — both are accepted, and any correct approach earns the points.
  7. Some coding tasks are graded 0 or 10 points only, others with partial credit (0–10 points); this is written in the header of every task.
