# Question bank → variant map (for the teacher only)

Source: `programming_exam_question_bank_en.docx` — Programming Fundamentals, 1st year, group 1248.

Every variant has 10 tasks: **4 theoretical + 6 coding**, 10 points each, 100 points in total.

* **Theoretical questions** (Theoretical Concepts): every variant has 2 questions from category A (Core Concepts, Memory, Types & Operators), 1 from B (Conditional Statements) and 1 from C (Loops).
* **Coding tasks**: every variant contains all 5 coding categories (A–E) + 1 extra task.
* No question appears in two variants. A topic and its second question / derived task (`-b`) are never in the same variant.
* Questions are not handed out in bank order, and the order of tasks is shuffled in every variant (two tasks of the same category never follow each other).
* The Word file has 15 theoretical topics and 25 coding tasks, while 20 + 30 are needed; therefore 5 topics have a second question on another aspect (`A2-b`, `A5-b`, `B1-b`, `C2-b`, `C3-b`) and 5 coding tasks are derived from bank tasks (`A11-b`, `A12-b`, `B7-b`, `D4-b`, `D9-b`).

Grading: `0 / 10` — only 0 or 10 points; `0–10 (partial)` — every correct part earns its own points. Checking is result-based: the function may return or print the answer, and any correct algorithm is accepted. Instructions such as *“without `swapcase()`”*, *“recursive”* or *“Bubble Sort”* are not enforced automatically — check the code in the admin panel if needed.
